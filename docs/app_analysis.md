# Bookmark App UI/UX 및 로직 분석 리뷰 (업데이트)

현재 `bookmark-app`은 초기 정적 프로토타입 단계에서 네이티브 기능 연동 및 주요 사용자 흐름 보완이 상당 부분 진행되었습니다. 현재까지의 개발 상황과 향후 과제를 정리했습니다.

---

## 1. 완료된 주요 업데이트 (Completed Features)

### 1-1. 기기 네이티브 기능 연동 (Native Integration)
*   **책 표지 업로드 (`register.tsx`):** `expo-image-picker`를 연동하여 카메라 촬영 및 갤러리 접근 기능을 구현했습니다. 선택된 이미지는 화면에 즉시 로드됩니다.
*   **OCR 문장 스캔 (`new-record.tsx`):** 카메라로 책 페이지를 촬영하고 텍스트를 추출하는 OCR 흐름을 구현했습니다.
    *   사용자 편의를 위해 추출된 전체 텍스트를 바텀 시트(Modal)에 띄우고, 필요한 부분만 복사할 수 있는 인터페이스를 제공합니다.

### 1-2. 편집 및 상태 관리 (Editing & State)
*   **책 정보 수정:** 도서 상세 화면에서 'Edit Book Info'를 통해 기존 정보를 수정할 수 있는 편집 모드를 지원합니다.
*   **직관적인 상태 변경:** 상세 화면의 상태 배지(Reading, Finished, Cancelled)를 직접 클릭하여 즉시 도서의 상태를 변경할 수 있습니다.
*   **화면 간 문맥 전달:** 상세 화면에서 기록 화면으로 이동 시 `bookId` 파라미터를 정상적으로 전달하여 해당 도서 정보가 노출되도록 수정되었습니다.

### 1-3. 사용자 경험 및 인터랙션 개선 (UX Improvements)
*   **키보드 대응 레이아웃:** `new-record.tsx` 및 `sentence.tsx`에서 키보드가 활성화될 때 입력창이 가려지지 않도록 동적 패딩 및 ScrollView를 적용했습니다.
*   **해시태그 시스템:** 문장 기록 시 해시태그를 자유롭게 추가하고 관리(입력/삭제)할 수 있는 완성도 높은 전용 UI를 구축했습니다.
*   **폼 유효성 검사:** 주요 저장 버튼 클릭 시 필수 입력값 누락 여부를 확인하는 알럿 로직을 추가했습니다.

---

## 2. 향후 과제 (Next Steps)

### 2-1. 실제 데이터 영속성 (Data Persistence)
*   **문제점:** 현재 모든 저장(Save) 로직은 기능 확인용 알럿(Alert) 처리만 되어 있으며, 실제 앱 재시작 시 데이터가 보존되지 않습니다.
*   **과제:** `AsyncStorage` 또는 `SQLite`를 활용한 로컬 데이터베이스 구축, 혹은 백엔드 서버 API 연동이 필요합니다.

### 2-2. 검색 및 필터링 고도화
*   **문제점:** 홈 화면(`index.tsx`)의 탭 필터링과 검색 기능이 여전히 정적 샘플 데이터만 보여주고 있습니다.
*   **과제:** 동적 데이터 배열(`state`)에 대해 필터링 로직을 실제 연동하여 화면에 반영해야 합니다.

### 2-3. 실 운영 OCR 연동
*   **현황:** 현재 OCR 기능은 시뮬레이션(Mock) 데이터를 사용 중입니다.
*   **과제:** 실제 프로덕션 단계에서는 Google Cloud Vision API 키를 활성화하거나, `react-native-mlkit-ocr`을 활용한 네이티브 빌드 프로젝트로 전환하여 실제 텍스트 추출 기능을 완성해야 합니다.

### 2-4. 데이터 공백 페이지 (Empty States)
*   **과제:** 아직 책이 한 권도 없거나, 특정 카테고리에 데이터가 없는 경우를 위한 안내 UI 및 일러스트 추가가 필요합니다.
