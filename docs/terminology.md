# Bookmark App 용어 정리

`bookmark-app` 서비스에서 사용되는 주요 용어와 개념을 정리한 문서입니다.

## 1. 핵심 개체 (Core Entities)

### 도서 (Book)
- 사용자가 읽고 있거나 읽을 예정, 또는 다 읽은 책을 의미합니다.
- **주요 정보**: 제목(Title), 저자(Author), 표지 이미지(Cover URL), 상태(Status).

### 문장 (Quote)
- 도서 내에서 사용자가 기록하고 싶은 특정 구절이나 문장을 의미합니다.
- 앱 내에서는 `Quote`로 부릅니다.
- **주요 정보**: 본문(Text), 기록 날짜(Date), 생각 수(Thoughts Count).

### 생각 (Thought)
- 책의 문장(Quote)을 작성한 후 나의 생각을 적은 것을 의미합니다.
- 앱 내에서는 `Thought`로 부릅니다.
- **주요 정보**: 본문(Text), 기록 날짜(Date)

### 기록 (Record)
- 도서에 대한 새로운 문장을 추가하거나 독서 활동을 남기는 행위 및 그 결과물을 의미합니다.

## 2. 도서 상태 (Book Status)

도서는 현재 독서 단계에 따라 다음 중 하나의 상태를 가집니다.
- **Reading (읽는 중)**: 현재 읽고 있는 도서.
- **Finished (다 읽음)**: 완독한 도서.
- **Cancelled (중단됨)**: 읽기를 중단한 도서.
- **All Books (전체)**: 상태와 상관없는 모든 도서 목록.

## 3. 주요 기능 용어

### 스캔 (Scan)
- 카메라를 통해 책의 문장을 촬영하고 텍스트로 변환하는 기능입니다.
- `NewRecordScreen`에서 `isScanning`, `handleScanText` 등으로 구현되어 있습니다.

### 태그 (Tag)
- 문장이나 기록에 분류를 위해 추가하는 키워드입니다.

### 타임라인 (Timeline)
- 문장에 대해 남긴 생각이나 관련 링크 등을 시간 순으로 보여주는 뷰입니다. (`QuoteDetailScreen` 참조)
- **이벤트 타입**:
    - `quote`: 문장에 대한 생각/메모.
    - `link`: 관련 참조 링크.

### 즐겨찾기 (Favorite)
- 특정 문장을 즐겨찾기로 등록하여 별도로 관리하는 기능입니다.

## 4. 화면 구성 (Screens)

- **Home (홈)**: 전체/상태별 도서 목록을 확인하는 메인 화면.
- **Log (로그)**: 기록된 문장들의 목록을 확인하는 화면.
- **Stats (통계)**: 독서 통계를 확인하는 화면.
- **Profile (프로필)**: 사용자 정보 및 설정을 관리하는 화면.
- **Book Detail (도서 상세)**: 특정 도서의 정보와 해당 도서에 기록된 문장들을 확인하는 화면.
- **Quote Detail (문장 상세)**: 특정 문장의 상세 내용과 타임라인을 확인하는 화면.
- **Register Book (도서 등록)**: 새로운 도서를 검색하거나 직접 등록하는 화면.
- **New Record (새 기록)**: 문장을 직접 입력하거나 스캔하여 기록하는 화면.
